## Aturan mengikat

1. `pageLanguage: "en"`. `includedLanguages: "en,id"`.
2. Setiap cangkang panel dan landing punya pengalih **EN | ID**.
3. String baru cukup Inggris. Tidak ada kewajiban kunci `t("…")` berpasangan `id`.
4. Jangan `locales/id`. Jangan teks Indonesia keras di komponen. Jangan rute `/id/...`.
5. Jangan diterjemahkan (`translate="no"` / `notranslate` / `<NoTranslate>`): nama orang, nama pusat, nomor rekening, kode QR, status mentah (`pending`, `published`), angka uang yang sudah diformat, merek NEXT.
6. Widget mengubah DOM. Lindungi React agar tidak pecah saat teks dibungkus `<font>`. Ini **bukan** fitur AI.
7. Simpan pilihan di `localStorage` (dan `profiles.locale` jika perlu). Nilai sah: `en` \| `id`.

Prosa dokumen dan tiket tetap memakai “Student”, bukan “Member”.
